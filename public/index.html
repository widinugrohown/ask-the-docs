A Measured RAG Assistant

Retrieval-augmented QA over the Ollama documentation. Every answer comes only from retrieved chunks and names the section it came from.

A password keeps this public endpoint from being used as a free LLM gateway.

What this demo does not prove. A citation shows a source was named, not that the answer is right. The corpus is public documentation, so a correct answer can come from the model's memory instead of from retrieval. The measured limits of this system — including a cross-lingual retrieval gap of 0/5 — are written up in the project README.
Built from raw parts (no LangChain): heading-aware chunking, a local embedding index, one provider-agnostic LLM client. FastAPI backend, containerised with Docker, static page on Netlify.
